Web application developed to allow users send hsm messages and send call lists in 3C Plus.

# Architecture 
## Frontend: 
- *Bootstrap* -> /public
- *Components*, *Layouts* & *Partials* -> /views
- *Style Sheets* -> /public/style.css
- *Page Behavior* -> /public/js

## Backend:
- *Routes* -> /routes
- *Models* -> /models
- *Repositories* -> /repositories (Only ERP database)
- *Services API* -> /services

## Login
- *Authentication Passport* -> /config/auth.js
